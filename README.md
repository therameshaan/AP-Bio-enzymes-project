# AP-Bio-enzymes-project

An interactive, animated 3D-style model that shows cellular respiration in a mitochondrion next to photosynthesis in a chloroplast. It was made for a high school biology video.


**## What it shows
**
**Mitochondrion (cellular respiration)****
- Glycolysis in the cytoplasm
- Link reaction forming acetyl CoA
- Citric acid cycle (Krebs cycle) in the matrix
- Electron transport chain on the inner membrane
- Chemiosmosis and oxidative phosphorylation through ATP synthase

**Chloroplast (photosynthesis)**
- Light reactions in the thylakoid with PSII and PSI
- Photolysis of water
- Photophosphorylation through ATP synthase
- Calvin cycle in the stroma with RuBisCO

## How to use

- Press Pause or Play to stop and start the motion
- Use the speed slider to slow things down or speed them up
- Click a stage button to spotlight one step and read a short caption
- Move your mouse over a panel to tilt it in 3D
- Use the color key at the bottom to identify each molecule type

## Run it locally

Download `index.html` and open it in any  browser. There is nothing to install.

## Built with

Plain HTML, CSS and JavaScript in a single file, with animated SVG graphics.
